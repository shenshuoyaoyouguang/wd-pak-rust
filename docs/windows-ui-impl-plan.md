### 1.3 粒度与编号

- 一个任务 = 一个可独立验收的落地单元，建议 0.5–3 人日；跨页面但不可分割的行为（如错误呈现）允许成为一个任务。
- 编号 `G{里程碑}-{两位序号}`；依赖只写直接前置，间接依赖由链式关系推导。
- “输入”写规格章节或上游任务输出；“输出”写可观察的界面件、规则或记录；“验收”写可复现的观察结果，不写实现方式。
- 不以代码模块、文件、函数为拆分单位；任务之间不规定技术实现顺序以外的结构。
- 本文 §4 是一级任务；本文 §8 是按依赖顺序展开的下一段二级子任务。一段完成并验收后再展开下一段，避免把未理解的细节提前拆死。

| 级别 | 定义 | 对里程碑的含义 |
| :--- | :--- | :--- |

## 2. 分层、数据流与状态

### 2.1 分层职责

| 层 | 持有数据 | 允许做的事 | 禁止做的事 |
| :--- | :--- | :--- | :--- |
| 界面外壳 | 窗口位置、导航状态、主题、焦点 | 承载页面、切换全局页面与包工作区、持久化布局 | 直接读写包文件 |
| 页面与视图 | 当前视图投影、选中集合、搜索条件 | 排序、筛选、高亮、展开折叠、定位 | 修改条目树与包内容 |
| 包会话 | 包路径、条目树快照、统计、文件指纹、内容读取通道 | 只读解析、按条目读取、计算存储比与 attrib 分布 | 写入、重命名、删除条目 |
| 写入通道 | 源文件、目标包、备份、临时产物 | 预检、备份、写临时文件、原子改名、清理临时产物 | 改变会话内容（写入后由会话重读） |
| 任务调度 | 任务记录、队列、进度、取消标记、日志缓冲 | 排队、串行化写任务、进度汇报、结果记录 | 弹模态框阻塞浏览 |
| 记录与通知 | 通知记录、未读状态、任务历史、校验结果 | 去重、合并、跳转、标记已读 | 改写任务结果 |
| 持久化 | 设置、最近打开、会话、任务历史、日志 | 读取、校验、回退默认、只读降级 | 保存半成品或损坏数据 |

### 2.2 包会话数据

| 数据 | 来源 | 生命周期 | 使用方 |
| :--- | :--- | :--- | :--- |
| 包路径与显示名 | 打开入口 | 会话建立到关闭 | 标题栏、状态栏、任务记录 |

| 统计：文件数、目录数、rootDirSize、fileSize、总存储、总原始、存储比、attrib 分布 | 条目集合推导 | 随条目集合重算 | 详情空选中、校验页、状态栏、包信息区 |
| 文件指纹：文件大小 + 修改时间 | 会话建立、刷新、写后重读 | 每次重读更新 | 校验结果过期判定 |
| 选中集合与主选中 | 用户选择、深层定位 | 视图切换与刷新后尽量保持 | 详情、命令栏禁用态、右键菜单 |

| 加载状态 | 解析进度 | 加载中到就绪 | 局部进度、取消关闭 |

| 写任务占用标记 | 任务调度 | 写任务排队到结束 | 关闭标签保护、写入口禁用 |

### 2.3 视图投影规则

条目集合不因浏览而改变；界面看到的是“投影”：

1. 范围：整个包，或当前目录（搜索筛选器可切换）。
2. 过滤：类型（全部/仅文件/仅目录）、压缩方式（全部/LZSS/原样）、搜索词（包内相对路径大小写不敏感子串，目录名参与，不做内容搜索）。
3. 排序：目录恒在文件前；同一组内按所选列升降序，未选列时按名称升序。
4. 展示：树视图按 `/` 层级展开；列表视图展示完整包内路径；命中子串高亮。
5. 选中保持：过滤或排序后，原选中项仍保留；不可见时保留选中但详情提示“当前筛选下不可见”；`Esc` 清空搜索后回到原选中项。

### 2.4 任务模型与队列

| 字段 | 含义 |
| :--- | :--- |
| 类型 | 导出、替换、打包、解包、浅校验、深校验 |
| 目标 | 包名或目录；用于串行判定与“在资源管理器中显示” |
| 状态 | 排队、运行中、完成、失败、已取消 |
| 步骤 | 预检、备份、写入、压缩、完成（按操作裁剪） |
| 进度 | 已完成/总数、当前条目或当前阶段 |
| 参数快照 | 压缩方式、并行度、是否备份、输出路径、校验模式 |
| 结果摘要 | 数量、字节数、存储比、耗时、产物路径、成功/失败计数 |
| 日志 | 含 `#` 前缀的 CLI 原文、错误原文、路径与时间 |
| 重试来源 | 由哪个失败任务发起，便于“用相同参数重试” |
| 取消点 | 该任务允许取消的阶段与取消后的清理规则 |

队列规则：

- 同一 PAK 的写任务串行；写入同一输出包、同一解包目录也视为冲突，串行执行。
- 读任务（浏览、搜索、浅校验）与写任务可并行；写完成后相关读结果按 §2.6 标记过期。
- 后提交的写任务显示“等待前一个写入任务完成”，不静默排队。
- 任务失败不自动重试；重试生成新任务并保留原记录。

### 2.5 状态机

| 对象 | 状态 | 进入条件 | 界面表现 | 迁移 |
| :--- | :--- | :--- | :--- | :--- |
| 包会话 | 加载中 | 打开、刷新、写后重读 | 局部进度或“正在加载 N 项”，可取消关闭 | 成功→就绪；失败→错误对话框，不建立可写会话 |
| 包会话 | 就绪 | 解析成功 | 标签、列表、详情、统计可用 | 刷新→加载中；关闭→释放 |
| 任务 | 排队 | 提交且存在冲突写任务 | 任务面板显示等待原因 | 前序结束→运行中；取消→已取消 |
| 任务 | 运行中 | 获得执行权 | 进度、当前条目、取消按钮（按阶段可用） | 完成/失败/取消 |
| 校验 | 未校验 | 打开包 | 状态栏“未校验” | 开始→运行中 |
| 校验 | 运行中 | 浅/深校验开始 | 进度与取消（深校验） | 完成→通过或发现问题；取消→已取消 |
| 校验 | 通过/发现问题 | 任务完成 | 通过为中性、发现问题为警告态 | 指纹变化或写操作→已过期 |
| 校验 | 已过期 | 包文件变化或发生写入 | 徽标“结果已过期”，提供重跑 | 重跑→运行中 |
| 预检 | 未检查/检查中/通过/阻断 | 向导步骤切换、重新检查 | 阻断时主按钮置灰，问题区展开 | 修正后重新检查 |
| 冲突决策 | 待决 | 同名覆盖、解包风险 | 对话框默认聚焦安全项 | 替换/改名/跳过；可应用全部 |
| 通知 | 未读/已读/失效 | 任务或校验结果产生 | 圆点 + 加粗；失效目标灰显 | 跳转、全部已读、清除 |

### 2.6 一致性规则

1. 写入成功后必须重读会话：条目集合、统计、指纹一起更新；选中项存在则保持，不存在则选中父目录并提示。
2. 写入使同包既有校验结果失效（不论是否完成），状态栏徽标与校验页同时标记“结果已过期”。
3. 外部修改包文件后，刷新时按指纹判定；仅校验结论标为过期，不自动重载浏览内容，由用户刷新或重新打开。
4. 关闭标签只释放浏览状态；有写任务进行中时拒绝关闭并说明原因。
5. 错误分三层：阻断性失败用错误对话框；局部失败用行内错误条；校验发现问题与警告用警告态，不弹阻断框。
6. 任务完成、失败、取消都以任务记录 + 通知呈现，不自动弹模态框。
7. 同一任务只产生一条通知；同类高频通知合并；系统通知仅在窗口不在前台时发送。
8. 所有“成功”文案的数值、路径与 CLI 输出一致；界面可省略 `#` 前缀，但不得改写数值与单位。
9. `cat` 的“不存在: …”与 `replace` 的“包内不存在: …”按原场景分别呈现，不合并为同一文案。

### 2.7 交互决策矩阵

| 场景 | 默认动作/焦点 | 禁用条件 | 取消或中断 | 结果反馈 | 依据 |
| :--- | :--- | :--- | :--- | :--- | :--- |

## 7. 边界与明确不做

1. 只可视化既有七项能力：`list`、`find`、`extract`、`pack`、`replace`、`cat`、`check`；不新增条目增删改、包内重命名、批量替换、目录整体导出、导出到标准输出、格式修复、加密或分卷。
2. 不改变 CLI 参数语义、退出码（0/1/2）与二进制格式；GUI 与 CLI 对同一输入必须产出相同字节。
3. 不做在线账号、云同步、团队协作、自动更新检查；“账户”仅为本地操作员档案与版本/许可信息（假设 A4）。
4. 不做应用内改名、非法名转义、大小写冲突自动处理；预检只提示并引导到资源管理器。
5. 不提供“强制打开”坏包、不提供校验修复、不把“校验通过”表述为“可安全解包”。
6. 预览只读且最多展示前 1 MB，导出内容不受预览截断影响。
7. 技术栈与平台集成方式由 `docs/windows-ui-tech-stack.md` 决定；本文不重复选型，只约束行为与验收。
8. 安装包、发布流水线与 CLI 的平台适配仍由 `docs/windows-plan.md` 的 M3/M4 负责，本文不重复拆分。
