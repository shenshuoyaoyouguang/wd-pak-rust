## 1. 产品定位

### 1.1 核心用途

把"问道服务端 PAK 资源包"的日常维护从命令行搬到可视化窗口，让使用者在同一个界面内完成：

1. **看**：打开 PAK，浏览目录树与条目元数据，搜索文件名。
2. **取**：把单个或多个条目导出到本地，供策划查看或交付。
3. **换**：用新文件替换包内某个条目，自动备份、自动刷新。
4. **打**：把整个目录重新打包为 PAK，控制压缩与并行度。
5. **验**：校验包结构（浅）或全量解压（深），拿到问题清单并定位条目。

### 1.2 目标用户

| 角色 | 典型诉求 | 界面侧重 |
| :--- | :--- | :--- |
| 服务端运维 / 发布负责人 | 热更新替换单个文件、发布前校验、批量打包，要求可回溯、防误操作 | 替换向导、校验报告、任务中心、备份提示、错误技术详情 |
| 策划 / 资源维护人员 | 找到某个配置文件、导出查看、确认条目是否存在，不关心命令行 | 搜索、树形浏览、详情面板、导出、文本预览、中文提示 |
| 项目技术负责人 | 排查坏包、确认压缩与大小分布、核对与命令行结果是否一致 | 包统计、校验问题清单、日志、CLI 文案对照 |

### 1.3 主要使用场景

| 编号 | 场景 | 关键路径 |
| :--- | :--- | :--- |
| S1 | 打开现有 PAK，确认某个配置在不在 | 打开 → 树形浏览/搜索 → 详情 → 复制包内路径 |
| S2 | 导出单个条目给策划确认 | 选中条目 → 导出 → 选择目录 → 打开所在文件夹 |
| S3 | 热更新：替换 `server_res_text.txt` 并留备份 | 选中条目 → 替换 → 选择新文件 → 备份开 → 执行 → 自动刷新并选中 |
| S4 | 从解包目录重新打包，发布前校验 | 从目录打包 → 预检（大小写/非法名/4 GB，含整包）→ 执行 → 校验 → 查看报告 |
| S5 | 收到"坏包"告警，定位损坏条目 | 打开 → 深度校验 → 问题表按类型筛选 → 双击定位 → 导出报告 |
| S6 | 同时处理 `etc.pak` 与 `lib_gs32.pak` | 多标签打开 → 标签间切换 → 各自校验/替换，写入任务按包串行 |
| S7 | 长任务期间继续浏览别的包 | 打包/深度校验进任务面板 → 继续浏览 → 完成通知 → 回看摘要 |
| S8 | 出问题后把现场交给开发 | 任务详情 → 复制诊断信息（版本、路径、原始错误文案） |

### 1.4 设计原则

1. **不隐藏 CLI 语义**：界面默认给中文人话，技术详情保留 CLI 原文（含 `#` 前缀消息与错误文本），便于与命令行结果对照。
2. **写操作可回退**：凡是改包的动作，事前给出预检与备份选项，事后给出产物路径与摘要；不提供静默覆盖。
3. **长任务不挡路**：超过约 2 秒的操作进入任务面板，界面保持可浏览；任务可取消且有明确结果。
4. **只读与写入视觉可分**：浏览、搜索、校验不改变文件；导出、替换、打包才写入，按钮与提示明确区分。
5. **状态可见**：当前包、当前目录、选中项、后台任务、校验结论始终在状态栏可见。

### 2.2 标题栏与命令栏

- **标题栏**：`wd-pak — <当前标签的包名>`；未打开包时为 `wd-pak`。悬停显示完整路径。使用系统标准窗口按钮；最大化时遵守 Windows 贴靠布局（Snap Layouts）。
- **命令栏**（单行，随上下文变化，图标 + 文本，可收起为图标）：
  - 无打开包：`打开 PAK`、`从目录打包`、`最近打开`、`设置`。
  - 已打开包：`打开 PAK`、`从目录打包`、`导出`、`替换`、`校验`、`刷新`、右侧固定搜索框、`任务`（带进行中数量徽标）、`⋯ 更多`。
  - 写入类按钮（导出/替换）在未选中合适对象时置灰，悬停说明原因（"请先选择一个文件条目""目录条目不支持导出"）。
  - 命令栏右侧的搜索框宽度随窗口收缩，最小保留图标态；`Ctrl+F` 聚焦。
- **标签页条**（命令栏下方）：每个打开的 PAK 一个标签，显示包名与关闭按钮；悬停显示完整路径与条目数。支持中键关闭、拖动重排、`Ctrl+Tab` 循环切换。不做"未保存"标记（PAK 修改即时落盘，无草稿态）。

### 2.3 导航区（左侧）

固定入口，自上而下：

| 导航项 | 作用 | 备注 |
| :--- | :--- | :--- |
| 工作台 | 启动页 / 首页：最近打开、拖放区、环境自检、快速开始 | 无包时默认页 |
| 最近打开 | 最近 PAK 列表（可固定、可移除、失效项灰显） | 与工作台共用数据 |
| 任务中心 | 运行中与历史任务、日志、结果摘要 | 徽标显示进行中数量，失败时变为警示色 |
| 通知 | 应用内通知中心 | 未读徽标 |
| 设置 | 六组设置页 | 底部固定 |
| 帮助 | 快速入门、快捷键、错误对照、诊断信息、关于 | 底部固定 |
| 账户与许可 | 本地操作员档案、版本与许可信息 | 底部固定，不显示登录态 |

- 导航区可折叠：宽度 220 DIP → 48 DIP 图标栏；折叠状态记忆。
- 导航项切换的是**全局页面**；包标签页属于"包工作区"，切到设置后再点标签可回到原包与选中项。
- 导航项支持键盘：`Tab` 进入、方向键移动、`Enter` 激活；不使用手风琴二级菜单（避免层级过深）。

### 2.4 内容区：标签页、视图与详情

- **两种浏览视图**，切换按钮位于面包屑右侧，状态按用户记忆：
  - **树视图**（默认）：按包内 `/` 层级展开，目录行名称带 `/` 后缀（与 `list` 输出一致），可展开/折叠、全部展开/折叠。
  - **列表视图**：扁平展示完整包内路径，适合排序与批量选择。
- **列**（列表视图与树视图的右侧列一致，可拖宽、可隐藏、可重置）：

| 列 | 内容 | 默认显示 |
| :--- | :--- | :--- |
| 名称 | 条目名；目录带 `/` 后缀 | 是 |
| 类型 | 文件 / 目录 | 树视图隐藏 |
| 原始大小 | `org`，字节；目录显示 `—` | 是 |
| 存储大小 | `size`，字节；目录显示 `—` | 是 |
| 压缩 | `原样 (RAW)` / `LZSS`；目录显示 `—` | 是 |
| attrib | `0x` + 8 位小写十六进制 | 否（详情面板可见） |
| offset | `0x` + 8 位小写十六进制 | 否 |
| mtime | 本地时间；悬停显示原始 Unix 秒 | 是 |
| 存储比 | 存储/原始，保留三位小数；原始为 0 时显示 `—` | 否 |

  - 排序：点击列头升/降序，目录恒在文件前（与资源管理器一致）；排序状态在切换视图后保留。
  - 列设置通过列头右键或"⋯ 更多 → 列"打开，提供"重置为默认列"。
- **详情面板**（右侧，默认展开，可拖宽或关闭）：
  - 标题：条目名；副标题：完整包内路径（可复制）。
  - 基本信息：类型、原始大小、存储大小、压缩方式、存储比。
  - 技术信息：attrib（十六进制 + 位解释：bit0 目录、bit31 原样，其余位按原值列出）、offset、mtime（本地时间 + 原始秒）。
  - 操作：`导出`、`替换`（目录条目置灰）、`复制包内路径`、`在列表中定位`。
  - 多选时显示汇总：`已选 N 项 / 合计原始 X / 存储 Y`，操作仅保留"导出所选"。
  - 空选中时显示当前包的统计摘要（文件数、目录数、总存储/原始、存储比、attrib 分布），与 `check` 报告头部同口径。
- **空状态**：未选中时，列表区域显示轻量提示"选择一个条目查看详情"；包为空（0 文件）时显示"包内没有文件条目"并提供"校验"入口。

### 2.5 任务面板与状态栏

- **任务面板**（内容区底部，可折叠，高度可拖拽并记忆）：
  - 折叠态只显示一行：当前任务名、进度条、`取消`、`展开`。
  - 展开态为任务列表：类型图标、目标、状态、进度、耗时、`查看详情`、`取消`（仅长任务）。
  - 任务完成或失败时，面板标题短暂高亮，并在通知中心留一条记录；不自动弹模态框。
- **状态栏**（底部，单行）：
  - 左：当前包完整路径（过长中间省略，悬停全路径）。
  - 中：`N 个文件 / M 个目录`、`存储 X / 原始 Y（存储比 Z）`。
  - 右：选中项信息（名称与大小）、后台任务数、校验结论徽标（未校验 / 通过 / 发现问题 N / 结果已过期）。
  - 状态栏不使用跑马灯文字；进度只在任务面板与任务栏按钮上表达。

### 2.6 导航模型与返回行为

- **层级**：全局页面（工作台/任务/通知/设置/帮助）↔ 包工作区（标签页）↔ 包内目录（面包屑）。
- **后退/前进**：`Alt+←` / `Alt+→` 仅在同一标签的目录历史内生效，不跨包、不跨全局页面；鼠标侧键同样映射。
- **面包屑**：`包名 / 目录 / 子目录`，每段可点击；末尾提供"复制当前路径"；点击包名回到包根。
- **深层定位**：从校验问题、搜索命中、任务详情跳转时，自动展开树、滚动到条目并选中，同时高亮 2 秒（不使用弹窗）。
- **关闭标签**：有写入任务进行中时不允许关闭，提示"该包有任务正在进行，完成或取消后可关闭"；关闭只释放浏览状态，不影响文件。

### 2.7 首次运行与常规运行

| 状态 | 表现 |
| :--- | :--- |
| 首次运行 | 直接进入工作台；最近打开为空；显示三张引导卡（打开 PAK / 从目录打包 / 拖入文件）；环境自检卡展开显示检查结果 |
| 常规运行（恢复会话开） | 恢复上次的标签、选中条目、窗口位置与布局；若包已不存在，降级为工作台并提示"上次打开的包已不可用" |
| 常规运行（恢复会话关） | 进入工作台，最近打开置顶 |
| 冷启动无包 | 不显示独立启动动画；解析文件时才出现局部加载指示，避免白屏 |

### 2.8 空状态、加载、错误与无权限的统一规则

| 状态 | 呈现要求 |
| :--- | :--- |
| 空 | 说明"为什么空"与"下一步做什么"，给一个主操作按钮；不使用纯插画占位 |
| 加载 | 局部骨架或进度条；超过 2 秒的操作转入任务面板，界面其余部分可操作 |
| 错误 | 行内错误条（可重试）用于局部失败；阻断性失败用错误对话框（见 4.7） |
| 无权限 | 明确说明"缺什么权限/文件被谁占用"，提供"重试""打开所在文件夹""复制详情"，不显示裸错误码 |

## 3. 核心功能模块

### 3.1 打开 PAK 与最近使用

**入口**：命令栏 `打开 PAK`；`Ctrl+O`；工作台"打开"按钮；拖入 `.pak` 文件；最近打开列表；系统跳转列表/托盘最近项；双击已关联的 `.pak`。

**界面构成**

- 系统文件打开对话框（记住上次目录，默认筛选 `*.pak`）。
- 最近打开列表：包名、完整路径、文件大小、条目数（解析成功后缓存）、最后打开时间；支持固定到顶部、从列表移除、清理全部。
- 失效项：灰显 + 警示图标，悬停说明"文件不存在或无访问权限"，提供"重新定位"。

**交互流程**

1. 选择文件 → 显示局部进度"正在读取目录表"。
2. 成功 → 新建标签页、切到包根、状态栏填入统计、写入最近打开（去重，同一路径已打开则直接激活该标签）。
3. 文件不存在 / 无读取权限 → 行内或对话框提示，提供"重新选择""打开所在文件夹"。
4. 格式错误（文件太小、魔数不对、目录表越界/大小异常、目录嵌套过深、目录表循环引用）→ 错误对话框，标题为"无法打开这个 PAK"，正文说明可能原因（文件截断、非 PAK 文件、复制不完整），技术详情给出原始错误文本；不提供"强制打开"。
5. 目录表解析超时或条目极多 → 先展示已解析部分，顶部显示"正在加载 N 项"，完成后自动消失；用户可取消并关闭标签。
6. 关闭标签后重新打开同一文件 → 重新读取，不缓存过期内容。

**边界**：打开是只读操作，不需要写权限；不修改文件时间戳。

### 3.2 包内容浏览

**入口**：打开包后自动进入；导航区"最近打开"选中项；标签页切换。

**界面构成**：树/列表视图、面包屑、列头、详情面板、状态栏统计、右键菜单（见 6.3）。

**交互流程**

1. 默认展开第一层目录，其余折叠；目录行在前，文件行在后，按名称升序。
2. 单击选中并联动详情；`Ctrl+单击` 多选、`Shift+单击` 连选；`Ctrl+A` 全选当前可见项。
3. 双击文件条目 → 打开只读预览（文本/十六进制，见 3.5）；双击目录 → 进入该目录（面包屑增加一级），`Backspace` 返回上级。
4. 排序或切换视图 → 保持当前选中项可见（滚动到视口）。
5. 列表刷新（`F5` 或替换后自动刷新）→ 保留选中项与滚动位置；若条目已不存在，选中其父目录并提示。
6. 条目数很多时启用虚拟滚动，滚动与排序不阻塞界面；列宽拖拽实时生效。

**目录条目规则**：目录不可导出、不可替换（按钮置灰，悬停说明"目录条目不支持该操作，请选择其中的文件"）；目录行的原始/存储大小显示 `—`，不臆造汇总值。

### 3.3 搜索与筛选

**入口**：命令栏搜索框、`Ctrl+F`、右键"在此目录中搜索"、空结果页"清除筛选"。

**界面构成**

- 搜索框：占位文本"搜索包内路径/文件名（不区分大小写）"，右侧显示命中数 `N 项` 与清除按钮。
- 可选筛选器（下拉，可叠加）：范围（整个包 / 当前目录）、类型（全部 / 仅文件 / 仅目录）、压缩方式（全部 / LZSS / 原样）。
- 结果沿用列表/树视图展示，命中子串高亮；状态栏显示"筛选中：N / 总数"。

**交互流程**

1. 输入即过滤（输入法组词期间不触发；停顿约 200 ms 后刷新），不阻塞输入。
2. 匹配语义与 `find` 一致：包内相对路径（含目录前缀）大小写不敏感子串，目录名参与匹配；不含条目内容搜索（明确写在空结果提示中）。
3. `Enter` 跳转第一个命中；`F3` 下一个、`Shift+F3` 上一个；`Esc` 清空并回到原选中项。
4. 无结果 → "没有匹配的条目"，提供"清除筛选""在整个包中搜索"（当范围为当前目录时）。
5. 关闭包或切换标签 → 搜索状态按标签独立保留。

**边界**：搜索只针对已打开的包，不扫描磁盘、不索引文件内容；不提供正则表达式（与 CLI 子串语义保持一致）。

### 3.4 条目详情

- 展示内容见 2.4；所有路径与数值支持选中复制，提供"复制包内路径""复制详情"（键值文本）。
- attrib 位解释只陈述确定含义（bit0、bit31），其余位标注"未定义/原值保留"，不做猜测。
- mtime 显示本地时间；原始 Unix 秒作为次要信息，避免跨时区误读。mtime 为 0 或明显越界时显示"未设置/异常值"并保留原始数字。
- 详情面板底部固定操作区，不随内容滚动。

### 3.5 导出（对应 `cat`）

**入口**：选中文件条目 → 命令栏 `导出`、右键 `导出…`、`Ctrl+E`、详情面板 `导出`；多选后 `导出所选`；条目拖到资源管理器（见 6.6）。

**界面构成（导出对话框）**

- 目标位置：目录选择器 + 路径输入；记住上次导出目录。
- 文件名：默认取包内路径的 basename（`\` 视为 `/`），可编辑；多选时不可编辑，按包内相对路径还原目录结构。
- 选项：`导出后打开所在文件夹`（默认关，记忆）。
- 冲突处理：目标已存在 → 询问"替换 / 改名保存 / 跳过"；多选时提供"全部替换 / 全部跳过"。
- 预览（可选页签）：文本条目显示只读文本，二进制条目显示十六进制；超过 1 MB 只预览前 1 MB 并注明"预览已截断，导出内容不受影响"。

**交互流程**

1. 确认 → 预检：条目是否为文件、目标目录可写、磁盘剩余空间。
2. 单条导出：短任务直接完成；多条或大文件进入任务面板，显示按条目计的进度与当前条目名。
3. 成功 → 通知 + 任务记录，语义与 CLI 一致（界面通知可省略 `#` 前缀）："已导出 N 字节 -> 绝对路径"；数值与绝对路径必须与 CLI 输出一致；若勾选则打开所在文件夹。
4. 失败 → 该条目标记失败并继续其余条目（多选场景），结束时汇总"成功 X / 失败 Y"，可展开失败原因（条目不存在、读取越界、数据不足、目标被占用、无写权限）。
5. 取消 → 停止后续条目；已完成的文件保留，未完成的半成品文件删除，不留下损坏文件。

**边界**：目录条目不可导出；不提供"导出整个包"（CLI 能力是 extract，应使用解包向导）；不提供写 stdout 的等价入口。

### 3.6 替换（对应 `replace`）

**入口**：选中单个文件条目 → 命令栏 `替换`、右键 `替换…`、`Ctrl+R`、详情面板 `替换`；把单个文件拖到选中条目上（见 6.6）。

**界面构成（替换向导，单页）**

- 只读区：包内路径、当前条目信息（原始大小、存储大小、压缩方式、mtime）。
- 新文件：路径输入 + 浏览 + 拖放区；显示文件大小、修改时间；选择后立即提示"大小变化 +X / −X 字节"。
- 压缩方式：`压缩（LZSS，默认）` / `不压缩（原样，RAW）`；说明"高熵大文件用原样可避免替换时内存占用升高"（与 BENCHMARK 结论一致）。
- 备份：`替换前创建备份` 默认勾选（与交互模式恒备份一致），显示备份路径 `<pak>.bak`；若该文件已存在，提示"同名备份将被覆盖"。
- 风险提示区（按需出现）：目标包只读、目标被占用、磁盘空间不足、新文件或整包超过 4 GB。

**交互流程**

1. 选择新文件 → 预检：文件存在且可读、大小未超 4 GB、目标 pak 可写、包内路径存在。
2. 确认 → 执行顺序：创建备份（若勾选）→ 写临时文件 → 原子替换；界面显示步骤条（备份 / 写入 / 完成）。
3. 成功 → 通知与任务记录，语义与 CLI 一致（界面通知可省略 `#` 前缀）："已替换 `<包内路径>`: N 字节 (存储 M 字节)"；若创建备份，附"已备份: `<pak>.bak`"；自动刷新当前包并重新选中该条目。
4. 备份失败 → 中止，原包不变，提示备份路径与原因（只读、被占用、空间不足）。
5. 目标被占用/不可写 → 错误对话框："目标文件被其他程序占用或不可写"，提供 `重试`、`打开所在文件夹`、`复制详情`；不自动重试。
6. 包内不存在 → 对话框说明"替换只能修改已有条目；新增文件需先解包、放入文件、再打包"，提供 `打开解包向导`、`取消`。
7. 写入失败 → 原包保持不变，临时文件已清理；错误详情保留原始文案。
8. 取消 → 在任何执行前取消不产生任何文件；执行中点"取消"仅在尚未写入时生效，写入阶段不可中断（按钮置灰并说明）。

**边界**：一次只能替换一个条目；不支持新增、删除、重命名、批量替换（多选时按钮置灰）；写入完成后不可撤销，只能依赖 `.bak` 人工回退。

### 3.7 打包（对应 `pack`）

**入口**：命令栏 `从目录打包`、`Ctrl+N`、工作台"从目录打包"、把目录拖入窗口、右键最近目录"打包为 PAK"。

**界面构成（四步向导）**

1. **源目录**：目录选择/拖放；显示扫描结果（文件数、目录数、总原始大小）；若目录内存在 `_pak_manifest.json`，提示"将按清单中的 order 排序并回填 mtime（attrib 由压缩选项重新决定），且该清单文件不会被打入包内"；列出被忽略的文件（仅 `_pak_manifest.json`）。
2. **输出**：目标 pak 路径；已存在时提示覆盖；显示预计所需空间与当前磁盘剩余空间。
3. **选项**：压缩（默认开）/ 不压缩（RAW，速度更快但体积更大）；并行度滑块 1–8，默认 `min(CPU 核数, 8)`，说明"1 = 顺序执行，实际并行上限为 8"。
4. **预检与执行**：预检通过后显示"开始打包"；执行中显示按条目计的进度、当前条目、已用时间，提供 `取消`。

**预检项（阻断性问题，必须在开始前全部解决）**

| 预检项 | 判定 | 界面动作 |
| :--- | :--- | :--- |
| 包内名过长/为空 | 空名或名称超过 43 个字符（Latin-1 下即 43 字节；错误文案写"43 字节"；CLI 对空名同样报"过长"） | 列出条目与原因，提供"复制路径""在资源管理器中显示" |
| 非法字符 | 含 `/`、`\`、NUL | 同上 |
| 非 Latin-1 字符 | 文件名含超出 Latin-1（> U+00FF）的字符 | 同上；提示沿用 CLI 文案"文件名含非 ASCII 字符" |
| 同层大小写冲突 | 同目录下小写相同但原名不同 | 列出冲突对，阻断；说明 Windows 解包会互相覆盖丢数据 |
| 超过 4 GB | 单文件原始/存储字节超 u32，或整包（头 + 目录树、根表）超 u32 | 阻断；单文件指出具体条目，整包超限说明总量 |
| manifest mtime 非法 | 清单中的 mtime 无法解析 | 阻断，定位到对应相对路径 |
| 目标不可写/被占用 | 无写权限或共享冲突 | 阻断，提供重试/换路径 |

- 预检问题支持"复制全部"与导出为文本；**不在应用内改名或编辑**，引导到资源管理器处理。
- 预检是本地扫描，不修改目录内容；大量文件时显示扫描进度并可取消。

**交互流程**

1. 选择源目录 → 扫描 → 显示统计与预检结果。
2. 任一项阻断 → "开始打包"置灰，问题区默认展开；修正后点"重新检查"。
3. 开始 → 任务面板显示进度；压缩模式显示压缩进度，原样模式说明"无压缩阶段，直接写入"。
4. 成功 → 摘要页：文件数、源大小、产物大小、存储比、耗时、输出路径；操作 `打开所在文件夹`、`立即校验`、`关闭`；任务记录保留摘要。
5. 失败 → 错误对话框 + 保留向导当前步骤与输入，允许修正后重试；原目标文件不被破坏（临时文件清理）。
6. 取消 → 停止写入，清理临时文件，原目标文件保持原状；摘要标注"已取消"。

**边界**：不提供追加打包（只支持整目录重建）；不提供加密、分卷、自定义压缩级别（CLI 无此能力）。

### 3.8 校验（对应 `check`）

**入口**：命令栏 `校验`、包信息区 `校验此包`、`Ctrl+Shift+K`、右键包标签/空白区、打包完成摘要"立即校验"。

**界面构成**

- 校验页（替换内容区，保留标签）：顶部为范围选择（`浅校验（结构）` 默认 / `深度校验（全量解压，较慢）`）与 `开始校验`。
- 统计区（与 CLI 报告同口径）：文件数、目录数、rootDirSize、fileSize、总存储、总原始、存储比、attrib 分布（按实际报告格式 `0x00000000x16`，即八位十六进制 + `x` + 计数）。
- 问题表：序号、类型、条目路径、详情、offset、size；支持按类型筛选、按路径排序、复制行、双击定位条目。
- 结论区：`校验通过` / `校验通过 (含全量解压)` / `发现问题 N 个` / `已取消`；旁注"本次校验时间"与"包文件已变化，结果可能过期"。
- 报告操作：`复制报告`、`导出报告…`（文本，结构与 CLI 报告一致，并注明 CLI 文本仅列前 50 条、界面展示全部）。

**问题类型**

| 类型 | 触发（浅/深） | 详情呈现 |
| :--- | :--- | :--- |
| 越界 | 浅：`offset + size` 超过 pak 文件大小 | 显示 offset/size 与文件大小 |
| 解压大小不符 | 深：解压得到长度与声明不一致 | 显示得到/声明字节数 |
| 解压失败 | 深：读取条目失败（越界、数据不足、目录引用异常、名字非法等） | 显示原始错误文本与条目路径 |

**交互流程**

1. 选择模式 → 深校验提示"将逐条解压，条目多时耗时较长"，可取消。
2. 执行 → 进度按已处理条目数显示；浅校验通常瞬间完成，不弹进度。
3. 完成（有问题）→ 结论为**警告态**而非错误态（对应退出码 1）；通知中心记一条"校验发现问题 N 个"，状态栏徽标变黄；不弹阻断对话框。
4. 双击问题行 → 切回该包的列表并定位条目；目录不存在时定位到最近父目录。
5. 关闭包或重新打开 → 校验结果与包文件指纹（大小 + 修改时间）绑定，变化后标记"结果已过期"，可一键重跑。
6. 校验中执行替换/打包 → 提示"校验基于当前文件，继续写入会使结果过期"，允许继续但结果自动作废。

**边界**：校验只读，不修复问题；**不检测大小写冲突与 Windows 非法文件名**（CLI 不检测），相关风险在解包/打包向导中单独提示，界面不得把"校验通过"表述为"可在 Windows 安全解包"。

### 3.9 解包（对应 `extract`）

> 虽然 CLI 的七项能力中解包属于 `extract`，但它是"目录 → 文件"的主入口，单列说明。

**入口**：命令栏 `⋯ 更多 → 解包到目录`、右键包标签/列表空白区。

**界面构成（向导）**

- 源包（只读，当前标签预填）、输出目录（默认上次目录，可浏览）。
- 选项：`解包后打开所在文件夹`；说明"将生成 `_pak_manifest.json`（记录条目顺序、attrib 与 mtime；再次打包时按 order 排序并回填 mtime，attrib 由压缩选项重新决定），不会打入新包"。
- 预检区（解包前扫描）：
  - 同层大小写冲突：列出冲突对，说明"Windows 上后写入者会覆盖先写入者，可能丢数据"；默认阻断，用户可显式勾选"我了解风险，仍然继续"（与 CLI 的警告后继续语义一致，但需确认）。
  - Windows 非法名/保留设备名/尾随点或空格：列出条目，默认阻断；说明这些名字在 Windows 上会失败或写入备用数据流。
  - 路径过长（超过 260 字符）：提示"可启用系统长路径支持或缩短输出目录"，不提供应用内绕过。
  - 目标目录非空：提示将合并写入，同名文件被覆盖。
  - 磁盘空间不足：显示所需/可用空间，阻断。

**交互流程**

1. 选择输出目录 → 预检 → 展示"将写入 N 个文件、M 个目录"。
2. 开始 → 任务面板按条目显示进度与当前路径；可取消。
3. 成功 → 摘要："解包完成：N 个文件 → 输出目录"，附 manifest 生成提示；可选"立即校验源包"或"从该目录打包"。
4. 部分失败（非法名、权限、磁盘满、文件被占用）→ 任务结束为"失败"，列出失败条目与实际路径；已成功写入的文件保留，明确说明"目录不完整"。
5. 取消 → 停止后续写入；已写入文件保留、不回滚（CLI 无取消能力，此为界面行为），提示可用同一目录继续解包（覆盖同名）。

**边界**：不提供"跳过非法条目的选择性解包"（列为未来可扩展）；不修改包内容。

### 3.10 任务中心与日志

**入口**：导航区 `任务中心`、命令栏 `任务` → 查看全部、状态栏任务数、完成通知。

`Ctrl+J` 仅切换任务面板；任务中心不设独立快捷键，面板标题栏提供"打开任务中心"。

**界面构成**

- 任务列表：状态（运行中/完成/失败/已取消）、类型、目标（包名或目录）、开始时间、耗时、结果摘要（如"N 个文件 / 存储 X"）、操作（查看详情、取消、在资源管理器中显示产物、复制详情）。
- 任务详情：步骤时间线（预检 → 备份 → 写入 → 完成）、参数快照（压缩/并行度/备份/输出路径）、完整日志（含 `#` 前缀的 CLI 文本与错误原文）、相关通知。
- 日志查看器：等宽字体、可搜索、可复制、可导出 `.txt`；默认自动滚动到底部，用户上滚后暂停自动滚动并提供"回到底部"。
- 保留策略：默认保留最近 100 条或 30 天（设置可调）；"清除已完成任务"不影响运行中任务。

**并发与串行规则**

- 同一 PAK 的**写任务**（替换、打包覆盖同一输出、解包写入同一目录）串行执行；后提交者在任务中显示"等待前一个写入任务完成"。
- 读任务（浏览、搜索、浅校验）可与写任务并行，但写完成后自动提示相关读结果可能过期。
- 深度校验与替换同时进行时，替换完成会将该校验标记为"结果已过期"。
- 任务失败不自动重试；提供"用相同参数重试"（若输入仍存在）。

### 4.7 错误对话框统一规范

| 区域 | 内容 |
| :--- | :--- |
| 标题 | 用户能理解的动作失败，如"无法替换这个文件""无法写入 PAK"；不使用"错误 2" |

| 技术详情 | 可折叠；保留 CLI 原始文案（如"魔数不对: 0x… (期望 0x11223344)"）、路径、退出码语义；提供复制 |
| 按钮 | 主操作（重试/打开所在文件夹）、次操作（复制详情）、关闭；危险操作不作为默认按钮 |

**常见错误映射**（原始错误摘自 CLI 实际输出；界面标题与建议为改写）：

| 原始错误 | 界面标题 | 建议 |
| :--- | :--- | :--- |
| 文件太小，不是 PAK | 无法打开这个 PAK | 确认文件完整、未被截断 |
| 魔数不对 | 这不是有效的 PAK 文件 | 确认选择的是 PAK，而非压缩包或备份 |
| 目录表越界 / 大小不是 64 的倍数 | 包目录表损坏 | 从备份恢复；不要用工具继续写入 |
| 包内不存在: {0}（如需新增文件请先 extract，放入文件后 pack） | 包内找不到这个条目 | 先解包→放入文件→重新打包 |
| 不存在: {0}（cat 专用） | 包内找不到这个条目 | 检查包内路径，或先在列表中定位 |
| 同目录大小写冲突 | 目录中存在仅大小写不同的文件 | 改名后重试；Windows 解包会互相覆盖 |
| 写出 pak 失败: 超过 4GB 上限 | 无法写入 PAK | 单文件超限则拆分；整包超限则拆分目录分批打包；该上限与是否压缩无关 |
| 目标文件被其他程序占用或不可写 | 目标文件正被占用 | 关闭占用程序后重试；或复制到其他目录操作 |
| 文件名过长: '{0}' (最多 43 字节) | 包内文件名过长 | 缩短名称后重试 |
| 文件名含非 ASCII 字符: '{0}'（pak 内文件名必须为 ASCII） | 包内文件名含非 ASCII 字符 | 改为 ASCII 名称后重试 |
| [Win32 206] 文件名或扩展名太长 | 输出路径超出 Windows 限制 | 启用长路径支持或缩短输出目录 |

## 5. 显示适配

### 5.1 窗口尺寸与断点

| 尺寸（DIP，逻辑像素） | 行为 |
| :--- | :--- |
| 最小 960 × 640 | 低于此尺寸不允许继续缩小；保证命令栏、列表、状态栏可用 |
| 默认 1280 × 800 | 首次启动居中于主显示器；之后恢复记忆位置 |
| ≥ 1440 宽 | 三栏常驻（导航 + 列表 + 详情），详情默认展开 |
| 1100–1439 | 详情面板可折叠，默认展开；导航保持 220 DIP |
| 960–1099 | 导航自动收为 48 DIP 图标栏；详情改为覆盖式浮层（Esc 关闭），列表占满 |
| 高度 < 760 | 任务面板默认折叠为单行；详情面板内容滚动，操作区固定 |
| 最大化 | 列表与详情按比例分配剩余宽度；列宽与面板宽度分别记忆 |

- 所有尺寸以 DIP 表达，不使用固定像素布局；列宽、面板宽度、任务面板高度持久化，并在下次启动时按当前 DPI 还原。
- 断点切换不丢失选中项、滚动位置与搜索条件；详情从常驻变浮层时，若原详情有焦点，焦点转移到列表选中行。

### 5.2 多显示器

- 窗口可在任意显示器间拖动；跨屏时按**目标显示器**的 DPI 重新布局，文字与控件不模糊、不跳变。
- 记忆窗口位置时记录"显示器标识 + 相对位置 + 尺寸（DIP）"；显示器拔除或分辨率变化后，若窗口大部分落在屏幕外，则回到主显示器居中，尺寸限制在可见工作区内。
- 最大化状态按显示器记忆；从副屏最大化状态拖回主屏时保持最大化并适配主屏工作区。
- 对话框与浮层居中于父窗口所在显示器；任务面板、搜索下拉、右键菜单不跨屏显示。
- 全屏预览（只读预览最大化）只在当前显示器生效；退出后恢复原窗口位置。

### 5.3 高 DPI 缩放

- 支持 100%–300% 系统缩放，重点验证 125%、150%、175%、225% 等非整数比例；采用按显示器独立缩放，切换显示器时即时重排。
- 图标提供多尺寸资源，按缩放选择最接近尺寸，不拉伸位图；1 DIP 分隔线随缩放渲染为 1–3 物理像素，保持清晰。
- 列表行高、列头高度、按钮内边距由字体度量推导，不写死像素；列头文字过长时省略并显示工具提示，不挤压相邻列。
- 缩放变化时保持滚动锚点（当前首行条目不变）、选中项与展开状态；不重建标签页。
- 拖放热区、复选框、关闭按钮等命中区域不小于 32 × 32 DIP；高缩放下不重叠、不截断。
- 日志与技术详情使用等宽字体，字号随系统缩放；十六进制数值不换行错位。

### 5.4 主题、暗色模式与高对比度

- 主题三态：亮色、暗色、跟随系统；跟随系统时监听系统主题变化并即时切换，不重启、不丢失界面状态。
- 强调色取系统强调色；语义色固定映射：成功（绿）、警告（黄/琥珀）、错误（红）、信息（蓝），在亮/暗主题下均满足正文对比度要求。
- 暗色模式下：列表斑马纹、选中态、悬停态、禁用态分别定义；不直接反转亮色资源；图标与插图提供双主题版本。
- 状态永远不只靠颜色表达：校验结论、任务状态、未读通知同时使用图标 + 文字；色盲友好。
- 高对比度模式：遵循系统主题色，禁用自定义背景图与半透明效果；焦点框、选中框可见；不覆盖系统的高对比度设置。
- 只读预览中的文本与十六进制着色需在暗色与高对比度下保持可读；不使用低对比度灰字承载关键信息。

### 5.5 文本缩放与动效

- 支持系统"文本大小"放大至 200%：关键信息（包名、条目名、按钮、错误原因）不截断；必要时换行或改为上下布局。
- 三种缩放口径的边界：显示缩放（DPI）100%–300% 见 §5.3；系统文本大小 100%–200% 由本段定义；应用内字号在系统文本基础上再按 100%–150% 调整（§4.3）。
- 面板过渡、通知滑入等动效短促（约 150–200 ms）；系统开启"减少动画"时改为无动画切换。
- 进度条动画仅在任务运行时启用；不确定进度使用系统标准不确定态，不自创闪烁效果。

- 任务完成/失败/校验问题时发送系统通知（受设置控制）；同一任务不重复通知。

### 6.7 文件对话框、最近使用与系统集成

- 使用系统标准打开/保存对话框；分别记忆"打开 PAK""导出目录""打包源目录""打包输出""解包目录"的最近位置。
- 默认文件名：导出取条目 basename；打包取源目录名 + `.pak`；备份固定 `<pak>.bak`。
- 覆盖确认：目标已存在时默认聚焦"取消"，明确显示将被覆盖的文件名与大小。
- 文件关联：安装时可注册 `.pak` 关联（可选），双击用 wd-pak 打开；重复打开同一路径的包时激活已有标签。
- 跳转列表：最近打开的 5 个 PAK + "打开 PAK…"任务；任务栏按钮显示当前任务进度，失败时叠加警示图标。
- 窗口缩略图工具栏不放置常用操作（避免误触写操作）。
- 系统"最近使用"与快速访问不写入导出文件记录（尊重隐私设置）。

### 6.8 无障碍支持

- 全部功能可仅用键盘完成；焦点顺序与视觉顺序一致，焦点框清晰可见（高对比度下仍可见）。
- 列表以表格模式暴露：行有名称（"文件名，原始 12.3 KB，LZSS"），列头可排序并有排序状态播报；树节点展开/折叠状态可朗读。
- 图标按钮、进度条、状态徽标均提供无障碍名称与帮助文本；不只依赖工具提示。
- 进度与结果使用礼貌级实时区域播报，节流不少于 5 秒一次；任务完成、校验结论、错误对话框出现时主动播报一次。
- 错误对话框焦点落在标题或首要建议上；技术详情折叠时不朗读冗长堆栈。
- 支持 200% 文本缩放、高对比度、减少动画；颜色不作为唯一信息载体（配合图标、文字、图案）。
- 拖放操作均有等价的菜单/快捷键路径；不强制使用鼠标。
- 屏幕阅读器下，搜索过滤后的结果数变化需播报"筛选中，N 项"。

### 6.9 Windows 文件系统边界的界面处理

| 边界 | 界面处理 |
| :--- | :--- |
| 目标被占用 | 显示"另一个程序正在使用此文件"，提供重试与打开所在文件夹；不自动结束其他进程 |
| 只读文件/目录 | 写入前预检并提示；建议复制到可写目录或手动去掉只读属性，不自动改属性 |
| 无写权限 / 需要管理员 | 不自动提权；提示更换输出目录（如用户目录），并说明原因 |
| 长路径（>260） | 环境自检显示"系统长路径支持：已启用/未启用"；解包向导对超长目标路径给出预警与缩短建议 |
| 非法 Windows 文件名 | 解包预检列出；打包时按 pak 规则校验（≤43 个字符，Latin-1 下即 43 字节；仅 Latin-1、禁止分隔符） |
| 大小写冲突 | 打包阻断并列冲突对；解包警告并要求显式确认 |
| 4 GB 上限 | 打包预检阻断；替换时新文件超限直接拒绝并说明格式限制 |
| FAT/exFAT 时间精度 | 在详情与任务摘要中注明"该磁盘时间精度为 2 秒，mtime 可能有偏差" |
| 杀毒/索引占用 | 写入失败时提示可能被安全软件扫描，建议稍后重试 |
| 磁盘空间不足 | 预检显示所需/可用空间；执行中空间耗尽则任务失败并保留原文件 |

### 6.10 通知与系统集成原则

- 系统通知只用于"需要知道结果"的事件：任务失败、校验发现问题、长任务完成；成功导出等轻量操作仅应用内提示。
- 通知内容包含包名与结果，不包含完整路径中的用户名等敏感信息（路径可在应用内查看）。
- 通知点击直达对应任务或校验页；目标已失效时打开通知中心并说明。
- 应用内通知与系统通知共享同一份记录，标记已读双向同步。

## 7. CLI 能力映射与不覆盖项

### 7.1 能力映射

| CLI 能力 | 界面入口 | 界面差异说明 |
| :--- | :--- | :--- |
| `list <pak>` / `-l` | 包浏览树/列表、详情面板 | 默认展示核心列；attrib/offset 放入详情或可选列；目录大小显示 `—`（CLI `-l` 显示的是目录表字节数） |
| `find <pak> <keyword>` | 搜索框 | 保持包内相对路径大小写不敏感子串语义；新增范围/类型/压缩方式筛选（界面层） |
| `extract <pak> <outdir>` | 解包向导 | 增加解包前冲突与非法名预检（CLI 仅对大小写冲突警告，非法名会写入失败）；仍生成 `_pak_manifest.json` |
| `cat <pak> <inner> -o <file>` | 导出对话框、拖出 | 默认文件名取 basename；增加只读预览与批量导出（逐条执行，语义不变） |
| `cat`（无 `-o`） | 不提供 | 界面始终写文件，避免二进制污染界面；预览为只读视图 |
| `pack <indir> <pak>` | 打包向导 | 压缩默认开；并行度 1–8（实际上限 8）；增加预检与覆盖确认 |
| `pack --no-compress` | 打包选项"不压缩（RAW）" | 与原样存储语义一致；界面说明无压缩阶段 |
| `pack --jobs N` | 并行度滑块 | 默认 `min(CPU, 8)`；`1` 为顺序；不提供 0 或超过 8 的输入 |
| `replace <pak> <inner> <newfile>` | 替换向导 | 单条目；压缩默认开；执行后自动刷新并选中 |
| `replace --backup` | "替换前创建备份"（默认开） | 备份路径固定 `<pak>.bak`；已存在时提示覆盖 |
| `check <pak>` / `--deep` | 校验页 | 浅/深切换；界面按已处理条目统计进度（CLI 无进度输出）；问题表可筛选定位 |
| `check` 退出码 1 | 结论"发现问题 N 个"（警告态） | 不作为错误弹窗；状态栏与通知呈现 |
| 交互模式菜单 | 主界面 + 七个功能入口 | 菜单项一一对应；默认值保持一致（压缩开、替换备份开、深校验关） |
| `--version`（输出 `1.0`） | 关于页、标题栏版本 | 原样显示 `1.0`，不添加前缀 |
| 退出码 0 / 1 / 2 | 任务成功 / 校验有问题 / 错误对话框 | 语义不变，仅可视化 |

### 7.2 明确不覆盖
